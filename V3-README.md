# KryptoHubb V3 — Customer Workspace

## Run locally

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. In the terminal run `npm install`.
4. Run `npm run dev`.
5. Open the URL printed by Vite, normally `http://localhost:5173/`.

## Customer workspace

- `/` — public site
- `/app` — dashboard
- `/app/portfolio` — portfolio
- `/app/markets` — markets
- `/app/trade` — sandbox trade UI
- `/app/wallet` — wallet
- `/app/deposit` — deposit placeholder
- `/app/withdraw` — withdrawal placeholder
- `/app/orders` — orders
- `/app/history` — transaction history
- `/app/kyc` — KYC
- `/app/settings` — settings

The financial actions are placeholders/sandbox UI. They do not move real money or crypto.
