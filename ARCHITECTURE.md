# KryptoHubb V4 Architecture

Public site -> Authentication -> Customer/Admin application -> Express API -> Database.

## Editing map

- Public: `client/src/features/public`
- Auth: `client/src/features/auth`
- Customer: `client/src/features/user`
- Admin: `client/src/features/admin`
- Shared UI: `client/src/components`
- Backend: `server`
- Database: `server/db`
